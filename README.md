# XLive 18

منصة اجتماعية وترفيهية للبالغين (+18)، تُطوّر على مراحل مع واجهة عربية RTL وهوية سوداء وحمراء، مع أولوية لتجربة الهاتف.

## الحالة الحالية

الموجود حالياً هو **أساس واجهة أمامية فقط**:
- `index.html`: هيكل الواجهة العربية والتنقل.
- `styles.css`: التصميم المتجاوب والهوية البصرية.
- `app.js`: التنقل المحلي وحالات توضح أن الخدمات الخلفية لم تُربط بعد.
- `docs/ROADMAP.md`: مراحل التنفيذ والقواعد والحالة الحالية.

لم تُنفّذ بعد قاعدة البيانات أو المصادقة أو رفع الفيديو الحقيقي أو الرسائل الخاصة أو البث المباشر أو الدفع. لا ينبغي اعتبار هذه الميزات جاهزة حتى تُربط وتُختبر فعلياً.

## معاينة الواجهة محلياً

يمكن فتح `index.html` في متصفح حديث. للحصول على تجربة أقرب إلى الاستضافة، شغّل خادماً محلياً ثابتاً من جذر المشروع، مثلاً:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## قواعد أساسية

- عدم عرض بيانات تجريبية على أنها بيانات حقيقية.
- لا يُنشر الفيديو للعامة قبل اجتياز المراجعة.
- التحقق من الهوية والصلاحيات في الخادم، لا في الواجهة وحدها.
- حماية الفيديو المدفوع في التخزين والتسليم، وليس بمجرد إخفاء المشغل.
- لا تُعلن المدفوعات أو البث أو أي ميزة مكتملة قبل اختبارها فعلياً.
- لا تُحفظ كلمات المرور أو مفاتيح API أو الأسرار في ملفات الواجهة العامة.
