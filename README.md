# XLive 18

منصة اجتماعية وترفيهية للبالغين (+18)، بواجهة عربية RTL وأولوية لتجربة الهاتف والخصوصية والأمان.

[حالة CI](https://github.com/xlive18official/xlive18/actions/workflows/ci.yml)

## الحالة الحالية

المشروع يتضمن واجهة مرتبطة بقاعدة بيانات Supabase فعلية، وتاريخ ترحيلات SQL مطبّق على المشروع المرتبط حتى `0024_index_saved_video_foreign_key.sql`.

- `index.html`, `styles.css`, `app.js`: الواجهة العربية المتجاوبة والتنقل وعرض المقاطع العامة المقبولة في الصفحة الرئيسية.
- `auth.js`: التسجيل والدخول واستعادة كلمة المرور، الملف الشخصي، البحث عن الحسابات، المتابعة وطلبات متابعة الحسابات الخاصة، الحظر، الرسائل، الإشعارات، الفيديوهات والمراجعة، البلاغات، طلبات الغرف والمحفوظات.
- `supabase/migrations/`: جداول وسياسات RLS وتخزين خاص وصلاحيات محدودة للمتصفح؛ راجع [دليل Supabase](supabase/README.md).
- `tests/smoke.test.js`: اختبارات بنيوية/ثابتة للمسارات الحساسة.
- `docs/ROADMAP.md`: الحالة المفصلة وما تبقى قبل الإطلاق.
- `docs/ADMIN_SETUP.md`: تعليمات إسناد دور المشرف بأمان من بيئة موثوقة.
- `docs/PROVIDER_DECISIONS.md`: نقاط اختيار مزوّدي التخزين والبث والدفع.

### التحقق الآلي

نجح آخر تشغيل موثق لـ GitHub Actions، متضمناً فحص صياغة JavaScript وتشغيل اختبارات smoke. هذا لا يغني عن اختبار المتصفح أو التحقق من العمليات الحقيقية بحسابين مختلفين.

## نشر نسخة معاينة على الإنترنت (Vercel)

أضفنا `vercel.json` لإعداد نشر الواجهة الثابتة. لإنشاء رابط معاينة عام، سجّل الدخول إلى Vercel بحسابك ثم افتح رابط استيراد المشروع:

**[استيراد مشروع XLIVE18 إلى Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fxlive18official%2Fxlive18)**

اختر المستودع `xlive18official/xlive18`، واترك إعدادات البناء فارغة لأن المشروع واجهة HTML/CSS/JavaScript ثابتة، ثم اضغط Deploy. بعد انتهاء النشر سيعرض Vercel رابطاً من نوع `*.vercel.app`. يلزم إكمال هذه الخطوة من حسابك؛ لا يمكن إنشاء مشروع استضافة داخل حسابك دون تفويض الدخول.

**مهم:** هذا نشر معاينة وليس إعلان جاهزية إنتاجية. قبل استقبال مستخدمين أو محتوى حقيقي، أكمل البنود الأمنية والتشغيلية أدناه واختبر الموقع المنشور.

## تشغيل الواجهة محلياً

يتطلب المشروع Node.js 20 أو أحدث لتشغيل الاختبارات. لعرض الواجهة، شغّل خادماً ثابتاً من جذر المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

لتشغيل الفحوصات:

```bash
npm run check:js
npm test
```

## إعداد Supabase

راجع [تعليمات Supabase](supabase/README.md) وتأكد من اختيار المشروع الصحيح قبل تطبيق الترحيلات. يستخدم المتصفح مفتاح publishable فقط؛ لا تضع مفتاح service-role في الواجهة أو GitHub.

## ما لم يكتمل قبل الإطلاق

- مراجعة تحذير أمني باقٍ على دالة البحث `public.search_profiles(text)` من نوع SECURITY DEFINER.
- اختبار المتصفح والتسجيل والدخول واستعادة الحساب والرفع والرسائل والصلاحيات فعلياً.
- اختيار وربط مزوّد بث مباشر/غرف وإصدار رموز دخول من خادم موثوق.
- اختيار مزوّد دفع يقبل النشاط المقصود، وتنفيذ webhook موثوق قبل تسجيل أي عملية شراء.
- إضافة فحص آلي للمحتوى، وعمليات مراجعة وتشغيل ومراقبة للإنتاج.
- اعتماد تحقق عمري مناسب قانونياً؛ تأكيد العمر داخل النموذج ليس تحققاً مستقلاً من العمر.
- اختيار ونشر استضافة إنتاجية وتكوين النطاق وHTTPS والنسخ الاحتياطية ومراقبة الأخطاء.

لا تستخدم المشروع لاستضافة محتوى حقيقي أو لتفعيل البث/المدفوعات قبل إكمال هذه الضوابط والتحقق من شروط مزوّدي الخدمات والقوانين ذات الصلة.
