# XLive 18

منصة اجتماعية وترفيهية للبالغين (+18)، تُطوّر على مراحل مع واجهة عربية RTL وهوية سوداء وحمراء، مع أولوية لتجربة الهاتف والخصوصية والأمان.

## الحالة الحالية

**الواجهة الأولية موجودة، ومخطط قاعدة البيانات مكتوب لكنه غير مطبّق على خدمة حقيقية.**

- `index.html`: هيكل الواجهة العربية والتنقل.
- `styles.css`: التصميم المتجاوب والهوية البصرية.
- `app.js`: التنقل المحلي وحالات واضحة للخدمات غير المتصلة.
- `supabase/migrations/`: مسودات SQL أولية للجداول وسياسات RLS وتخزين فيديو خاص؛ لم تُشغّل على قاعدة بيانات بعد.
- `docs/ROADMAP.md`: مراحل التنفيذ والحالة الحالية.
- `docs/PROVIDER_DECISIONS.md`: مقارنة خيارات الاستضافة المجانية والتنبيهات الخاصة بمزوّدي محتوى +18.

لم تُنفّذ بعد المصادقة المتصلة بالواجهة، أو رفع الفيديو الحقيقي، أو الرسائل الخاصة، أو إصدار رموز الغرف، أو البث المباشر، أو الدفع. لا تُعتبر هذه الميزات جاهزة حتى تُربط وتُختبر فعلياً.

## معاينة الواجهة محلياً

افتح `index.html` في متصفح حديث، أو شغّل خادماً محلياً ثابتاً من جذر المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## إعداد الخلفية لاحقاً

راجع [تعليمات Supabase](supabase/README.md) قبل تشغيل ملفات الترحيل، وراجع [مقارنة الاستضافة والمزوّدين](docs/PROVIDER_DECISIONS.md) قبل اختيار خدمات التخزين أو الغرف أو الدفع. ملفات SQL وحدها لا تنشئ خدمة سحابية ولا تُطبّق تلقائياً.

## قواعد أساسية

- عدم عرض بيانات تجريبية على أنها بيانات حقيقية.
- لا يُنشر الفيديو للعامة قبل اجتياز المراجعة.
- التحقق من الهوية والصلاحيات في الخادم، لا في الواجهة وحدها.
- حماية الفيديو المدفوع في التخزين والتسليم، وليس بمجرد إخفاء المشغل.
- لا تُعلن المدفوعات أو البث أو أي ميزة مكتملة قبل اختبارها فعلياً.
- لا تُحفظ كلمات المرور أو مفاتيح API أو مفاتيح الخدمة السرية في ملفات الواجهة العامة أو GitHub.
- يجب اعتماد مزوّدي خدمات يسمحون صراحةً بنوع المحتوى المقصود، مع التحقق من العمر والموافقة والبلاغات.
