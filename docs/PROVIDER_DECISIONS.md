# XLive 18 — خيارات الاستضافة المجانية

آخر مراجعة: 2026-10-11. الأسعار والحصص تتغير؛ راجع صفحات المزوّد الرسمية قبل إنشاء الحساب أو الاعتماد التجاري.

## القرار المبدئي

ابدأ بواجهة ثابتة مجانية، وخلفية قاعدة بيانات/مصادقة منفصلة، ولا ترفع فيديوهات المستخدمين إلى مستودع GitHub. هذا اختيار للتطوير والاختبار الأولي فقط، وليس وعداً بأن منصة فيديو وبث كبيرة ستظل مجانية.

| الجزء | المرشح الأول | التكلفة الابتدائية | ملاحظات وحدود |
|---|---|---:|---|
| استضافة الواجهة | Cloudflare Pages | 0 دولار | مناسبة لملفات HTML/CSS/JS الثابتة. حد البناء المجاني المنشور 500 بناء شهرياً، مع حدود للملفات والحجم. |
| قاعدة البيانات والمصادقة | Supabase Free | 0 دولار | يشمل Postgres وAuth وRealtime. الحصص المنشورة تشمل 500 MB لقاعدة البيانات و1 GB للتخزين و5 GB للخروج، ومشاريع المجاني قد تتوقف مؤقتاً بعد أسبوع من عدم النشاط. |
| ملفات الفيديو | لا نعتمد مزوّداً قبل مراجعة السياسة والتكلفة | غير محسوم | تخزين Supabase المجاني (1 GB ورفع حتى 50 MB وفق صفحة التسعير) صغير لمنصة فيديو. يمكن تقييم تخزين كائني خاص مع روابط موقعة، لكن يجب التحقق من سياسة المحتوى وقيود التوزيع قبل الاستخدام. |
| غرف الصوت والفيديو | خدمة WebRTC/SFU تُختار بعد مراجعة شروط محتوى +18 | غير محسوم | LiveKit Cloud يعلن حصة مجانية للمشروع التجريبي، منها 5,000 دقيقة مشارك WebRTC و50 GB نقل بيانات في صفحة الحصص؛ لكن سياسة المحتوى والعقد يجب تأكيدهما كتابياً قبل الاعتماد على خدمة سحابية لمنصة محتوى بالغين. |
| الدفع | لم يُختَر | غير محسوم | كثير من معالجي الدفع يقيّدون المحتوى الجنسي/البالغين. لا نربط أي مزوّد قبل التأكد من قبول نشاط +18 كتابةً، بما يشمل المحتوى الذي ينشئه المستخدمون والاشتراكات والبث. |

## المخاطر التي يجب ألا نتجاهلها

1. **مجانية التطوير لا تعني مجانية الإنتاج.** الفيديو والبث يستهلكان التخزين والخروج من البيانات ودقائق المشاركين بسرعة.
2. **الامتثال قبل اختيار المزوّد.** لا يكفي أن تسمح صفحة التسعير بالتسجيل؛ راجع سياسة المحتوى وشروط الاستضافة والدفع واطلب تأكيداً مكتوباً عند الغموض.
3. **الأمان في الخادم.** مفاتيح الخدمة السرية لا توضع في المتصفح أو GitHub. مفاتيح LiveKit الخاصة وتوقيع روابط الفيديو يجب أن يبقيا على خادم موثوق.
4. **الفيديو المدفوع.** تخزين خاص، تحقق من الدفع على الخادم، وروابط قصيرة العمر بعد التحقق فقط. لا نعتمد على إخفاء زر أو مشغل في الواجهة.
5. **السلامة +18.** يلزم التحقق من السن، وإثبات الموافقة والحقوق، والإبلاغ والحظر ومراجعة المحتوى، وسياسة واضحة ضد أي محتوى غير قانوني أو غير رضائي. يجب وضع إجراءات استجابة للبلاغات قبل الإطلاق.

## الخطة المرحلية

- المرحلة A: الواجهة + إعداد مخطط قاعدة البيانات والسياسات، بلا أسرار.
- المرحلة B: إنشاء حسابات المزوّد يدوياً بواسطة مالك المشروع، ثم تطبيق migrations واختبارها.
- المرحلة C: توصيل المصادقة والملفات الشخصية.
- المرحلة D: اختيار تخزين فيديو خاص متوافق مع طبيعة المحتوى واختبار رفع/تنزيل وصلاحيات الوصول.
- المرحلة E: اختيار خدمة الغرف بعد تأكيد السياسة والتكلفة؛ إصدار رموز الغرف من الخادم فقط.
- المرحلة F: اختيار الدفع بعد موافقة المزوّد على النشاط صراحةً.

لا يوجد حالياً حساب Supabase أو Cloudflare أو LiveKit مربوط بالمستودع، ولم يتم إنشاء أي خدمة سحابية أو نشر الموقع.
